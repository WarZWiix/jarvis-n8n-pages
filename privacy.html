JARVIS n8n - Privacy policy

Last updated: October 31, 2026

Who this applies to

JARVIS n8n is a personal, self-hosted application used only by its owner, to access the owner's own Gmail account. It has no other users.

What data is accessed

With the owner's consent, the application accesses Gmail messages in the owner's own mailbox: sender, subject, date, labels and content as needed to list unread messages and to archive, label or delete messages when the owner asks for it.

How the data is used

The data is used only to provide these mailbox functions to the owner. It is not used for advertising, profiling or analytics. Message content is processed by software running on the owner's own computer.

Storage and sharing

The application does not sell Google user data and does not share it with third parties. Access tokens are stored in the owner's own self-hosted n8n instance. Messages are not copied to any external service by this application.

Google API Services User Data Policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revocation

Data is kept on the owner's computer only as long as the owner chooses. Access can be revoked at any time at https://myaccount.google.com/permissions, and by deleting the credential in the owner's n8n instance.

Contact

For any question, contact the owner through the GitHub account that hosts this page.
